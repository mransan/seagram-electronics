# Goal 

Our contribution guideline specifies an 80 character limit. Rather than creating over and over 
a script to implement this limit for each task, create one and let's check it in 
this repository under the @scripts folder. Update README.md with instructions on 
how to run the script to make a markdown file compliant with the character limit. 


# Contribution guideline

- create a dedicated branch in git to perform the task
- once the task initial implementation is complete, push to origin and create a pull request 
- keep lines under 80 characters 
- update the README.md file concisely after completing the task to help a coding agent understand what has been done and build on top.
