# Technical Specifications

* **Sensor Type:** Piezoresistive MEMS barometric air pressure and temperature
* **Package:** 8-pin VLGA-8-2 with metal lid and protective silicone gel ($2.0
  \times 2.5 \times 1.1\,\text{mm}^3$)
* **Environmental Protection:** IPx8 waterproof certified (submersible to 50 m
  underwater for 1 hour, ISO 22810 standard), resistant to dust and humidity
* **Operating Pressure Range:** 300 hPa to 1200 hPa (~-500 m to +9000 m
  relative to sea level)
* **Pressure Accuracy & Precision:**
  * **Relative Accuracy:** $\pm 0.06\,\text{hPa}$ (equivalent to $\pm
    0.5\,\text{m}$ altitude)
  * **Absolute Accuracy:** $\pm 1.0\,\text{hPa}$ ($\pm 8\,\text{m}$)
  * **Precision (Noise RMS):** $\pm 0.002\,\text{hPa}$ ($\pm 0.02\,\text{m}$ /
    $\pm 2\,\text{cm}$ in ultra-high resolution mode)
  * **Temperature Coefficient of Offset (TCO):** $0.5\,\text{Pa/K}$
* **Temperature Sensor:**
  * **Operational Range:** -40°C to +85°C
  * **Accuracy:** $\pm 0.5^\circ\text{C}$
* **Electrical Supply:**
  * **Supply Voltage ($V_{\text{DD}}$):** 1.7 V to 3.6 V DC (typically 3.3 V
    DC)
  * **I/O Digital Voltage ($V_{\text{DDIO}}$):** 1.2 V to 3.6 V DC
* **Current Consumption:**
  * **Pressure Measurement:** $1.7\,\mu\text{A}$ at 1 Hz sampling rate
  * **Temperature Measurement:** $1.5\,\mu\text{A}$ at 1 Hz sampling rate
  * **Standby Mode:** $0.5\,\mu\text{A}$
* **Digital Communication Interfaces:**
  * **I2C:** Supports Standard Mode (100 kHz), Fast Mode (400 kHz), and
    High-Speed Mode (up to 3.4 MHz)
  * **SPI:** 3-wire and 4-wire SPI (clock rates up to 10 MHz)
* **FIFO Buffer:** Integrated 32-measurement hardware FIFO storing pressure and
  temperature samples to minimize host processor wakeups

# Hardware Integration and Pinout

The bare IC (RS part 236-3647) is an ultra-compact 8-pin LGA package intended
for SMD reflow soldering on custom PCBs. For DIY marine gateway installations,
it is typically integrated via an evaluation breakout (e.g. Infineon Shield2Go
/ Kit2Go `KITDPS3682GOTOBO1`, or custom breadboard adapters).

```
                      DPS368 VLGA-8-2 Pin Layout (Top View)
                           +-------------------+
             GND (Pin 1) --| 1               8 |-- VDD (1.7V - 3.6V)
             CSB (Pin 2) --| 2    [ VENT ]   7 |-- GND
      SDI / SDA (Pin 3) --| 3               6 |-- VDDIO (1.2V - 3.6V)
      SCK / SCL (Pin 4) --| 4               5 |-- SDO / ADDR Select
                           +-------------------+
```

## Pin Allocation Table

| Pin No. | Pin Name | I2C Mode Function | SPI Mode Function | Connection Notes |
| :---: | :---: | :--- | :--- | :--- |
| **1** | **GND** | Ground reference (0V) | Ground reference (0V) | Connect to common DC ground |
| **2** | **CSB** | Chip Select (Tie to VDDIO) | Chip Select (Active Low) | Leave floating or pull up for I2C |
| **3** | **SDI** | Serial Data (SDA) | Serial Data In (MOSI) | Requires 2.2k–4.7kΩ pull-up to 3.3V |
| **4** | **SCK** | Serial Clock (SCL) | Serial Clock (SCK) | Requires 2.2k–4.7kΩ pull-up to 3.3V |
| **5** | **SDO** | I2C Address Selector / IRQ | Serial Data Out (MISO) | Sets I2C address (0x77 vs 0x76) |
| **6** | **VDDIO**| Digital I/O supply | Digital I/O supply | Connect to +3.3V rail |
| **7** | **GND** | Substrate Ground | Substrate Ground | Connect to common DC ground |

## I2C Addressing and SDO Configuration

The DPS368 supports two selectable 7-bit I2C slave addresses controlled by the
voltage level applied to pin 5 (`SDO`):

* **Address `0x77` (Default):** Active when `SDO` is connected to
  $V_{\text{DDIO}}$ (or left floating with internal bias on supported breakout
  boards).
* **Address `0x76` (Alternate):** Active when `SDO` is pulled down to Ground
  (GND).

> [!NOTE] If used on the same I2C bus alongside a Bosch BME280 sensor (default
> `0x76`), configure the DPS368 to address `0x77` to prevent bus address
> collision.

# Integration with HALMET and Marine Gateways

The DPS368 functions as a precision barometric sensor for boat weather
forecasting, pressure drop alarms, and true barometric pressure telemetry
broadcast onto NMEA 2000 and Signal K networks.

```
                   HALMET to DPS368 I2C Wiring Architecture
+------------------------------------+          +---------------------------+
| HALMET Marine Controller           |          | DPS368 Breakout / Module  |
|                                    |          |                           |
| [ Qwiic Port / 4-Pin 2.54mm Header]|          |                           |
|   Pin 1 (GND) ----------------------------------> GND (Pin 1 & 7)        |
|   Pin 2 (3V3) ----------------------------------> VDD & VDDIO (Pin 6 & 8) |
|   Pin 3 (SDA / GPIO 21) ------------------------> SDI / SDA (Pin 3)       |
|   Pin 4 (SCL / GPIO 22) ------------------------> SCK / SCL (Pin 4)       |
|                                    |          |                           |
|   ESP32 Core (Xtensa 240 MHz)      |          | SDO (Pin 5) -> VDD (0x77) |
|   Internal ADS1115 ADC (@ 0x48)    |          | CSB (Pin 2) -> VDDIO      |
+------------------------------------+          +---------------------------+
```

## Marine Environment Advantages
1. **IPx8 Waterproof Rating:** Marine cabin and bilge environments frequently
   experience 100% relative humidity, salt air condensation, and occasional
   spray. Standard commercial barometers (e.g. BMP280/BMP388) use open vent
   cavities that can foul from moisture deposition or salt crystals. The
   protective silicone gel layer inside the DPS368 vent port allows pneumatic
   pressure transmission while completely shielding the internal MEMS membrane
   from moisture and corrosion.
2. **High Pressure Resolution:** With $\pm 0.002\,\text{hPa}$ precision, the
   sensor can detect minute barometric pressure tendencies hours ahead of
   approaching squalls or frontal depressions.
3. **No Address Conflict with HALMET:** Because HALMET's built-in ADS1115 ADC
   resides at I2C address `0x48`, the DPS368 (at `0x77` or `0x76`) can be
   connected directly onto the HALMET Qwiic / I2C bus without needing an I2C
   multiplexer.

## Software Driver Implementation (SensESP / Arduino)

Infineon provides the open-source **`Dps3xx` / `Dps368` Arduino library**
compatible with ESP32 microcontrollers:

```cpp
#include <Wire.h>
#include <Dps368.h>

Dps368 baroSensor;

void setup() {
  Wire.begin(21, 22); // ESP32 default I2C pins on HALMET
  
  // Initialize at default address 0x77 (or 0x76 if SDO is tied to GND)
  int16_t status = baroSensor.begin(Wire, 0x77);
  if (status != 0) {
    Serial.println("Error initializing DPS368!");
  }
}

void loop() {
  float pressure;
  float temperature;
  uint8_t oversampling = 2; // High-precision oversampling

  // Read pressure in Pascals (convert to hPa by / 100.0)
  int16_t ret = baroSensor.measurePressureOnce(pressure, oversampling);
  if (ret == 0) {
    float pressure_hPa = pressure / 100.0;
    // Broadcast via NMEA 2000 PGN 130310/130314 or SensESP Signal K path
  }
  delay(1000);
}
```

# NMEA 2000 and Signal K Data Mapping

* **NMEA 2000 PGN 130310 (Environmental Parameters):** Atmospheric pressure
  transmitted with $100\,\text{Pa}$ resolution.
* **NMEA 2000 PGN 130314 (Actual Pressure):** High-resolution atmospheric
  pressure transmitted in Pascals ($1\,\text{Pa}$ resolution).
* **Signal K Key:** `environment.outside.pressure` (transmitted in Pascals,
  e.g. $101325\,\text{Pa}$).
